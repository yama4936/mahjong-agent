# 三麻友人戦192の左ポン待ち画像の試行

192の保存画面では、ポン／スキップ待ち中に発光とボタン周辺の差分で16回連続の再観測となり、120秒で操作者が停止した。固定した画面比較を変更する前に、これは実動作の完走や段位戦の勝率を示さない。

試行は画像中の左ポン表示に限る。両画面で保存した矢印テンプレートを指定位置に照合し、供出牌の領域の色・形を検査する。周囲の緑〜青緑色の発光と、左の琥珀色表示で両画像とも条件に合う画素だけを比較から除く。ポン／スキップ行の局所しきい値は、この試行に限り10から30にする。検証を通らない場合は拒否する。操作可能な経路は検証済み300+0の三麻CPU友人戦だけであり、入力後の結果は未確認として扱う。

保存192の1組で試行判定が通過し、実際の友人戦見送り関数に保存画像と模擬画面を渡してスキップ1回を確認した。テストはロン行・別牌・手牌・局面・表示の変化を拒否する。独立確認では画面内の手牌13枚をそれぞれ供出牌位置へ縮小貼付して13件を拒否した。ただし、4×4画素の白・緑・水色など一部の人工的な変化は見逃す。これらが実際の異牌を意味するかは未確認で、1組の保存画面だけで全局面の安全性は証明できない。実対局の回帰は別途必要。

# 三麻友人戦の打牌クリック予算

友人戦187（300+0、`action-deadline-ms=300000`、`force-auto-click-budget-ms=8000`）では、南の打牌候補から試行まで約8.73秒、元フレームから約12.26秒かかった。詳細な起動設定と記録は `docs/sanma-friend-regression-187-20261112.md` を参照。旧三麻打牌経路は300秒の操作期限と短い画面鮮度だけを検査し、指定の8000msを適用していなかった。

対処案は元画像の撮影開始を操作者内で同じ観測・画像ハッシュに束縛し、認識や再撮影の終了時刻で予算を更新せず、選択と確認のクリック前まで同じ予算を検査する。初回入力後に期限が切れた場合、選択状態は未確定として中断する。期限切れは自動で再観測を続行せず安全停止する。処理速度を上げる変更ではない。

範囲は三麻CPU友人戦の実験的打牌経路だけで、北抜き、ポン／スキップ、リーチ、ツモにはこの予算制限を追加していない。実友人戦での変更後の完走や、段位戦での有効性は未検証。

追加の試験版は、北抜き・ポン／カンの見送り・リーチ宣言・ツモ・ロンの入力にも同じ撮影開始時刻からの予算を適用する。リーチ宣言後の牌選択と確認も元の観測時刻を引き継ぎ、途中で期限を超えたときは宣言済みまたは牌選択が未確定の状態で停止する。ロン／ツモも8秒超では入力せず停止する。これは操作の鮮度制限であり、速度向上や勝率改善の証明ではない。入力可否の検証は保存画像と模擬画面であり、この追加変更後の実友人戦での完走は未検証。

# Client-specific four-pin candidate

`4p__6c_friend.png` is an upright crop from a 300+0 CPU friend match. It is not part of the external bootstrap dataset. Install it only between matches using `node scripts/install-client-templates.mjs`; restart the operator so its recognition process reloads the template set. Installation affects all recognition using that directory, including four-player mode. The template comparison remains an unverified candidate and does not establish accuracy or game state.

One independent friend-match draw crop (`test/fixtures/fourpin-review/4p-ba2-heldout.png`) improved from 0.89588 to 0.99919 without using that image as the template. The repository bootstrap holdout set of 105 images showed no newly high-confidence incorrect label, but there was one pre-existing high-confidence 5m/0m label discrepancy and 30 pre-existing disagreements overall. Labels in that corpus are not independent human adjudications. The additional eleven-tile image comes from a different friend match; its labels are candidate observations, not independently certified. Three games and this finite corpus cannot establish absence of false positives in live or ranked games.

The comparison test requires the generated `templates/bootstrap/` dataset; it is skipped when that directory is absent. A passing test from another environment does not imply the local template dataset is present or was evaluated. The installer preserves an existing different file under the same name and exits with an error; an identical file is left in place.

# Friend-only unobscured action-row hypothesis

The resident row classifier can return `unresolved` for its rightmost slot even when the entire slot appears empty. For friend-mode shape selection only, this path independently compares all visible pixels of the first two slots against the existing empty-row reference and the full right slot against the existing `sanma-friend-empty-slot-6c.png` empty reference. It rejects any right-slot pixel difference above 30 or any 16×16 block whose mean RGB difference exceeds 3. It accepts no extracted-north overlap references. It does not change the recognizer's `unresolved` status, establish that the player is not in riichi, prove that a UI element is absent, or bypass the existing hand, points, position, self-turn hypothesis, priority or pre-click freshness checks. Hidden or changed pixels still prevent this new hypothesis when outside these bounds.

On cd82c23 `manual-1-before.png`, the right slot differs from that reference by at most 1 intensity unit per channel and block mean at most 0.63; an offline replay of the same image's resident recognition produces a 1-sou structural candidate, while the observed draw is South. With mock discard execution the unverified 1-sou plan reaches the existing input adapter. Original run logs selected draw-only and then stopped on a changed pre-click frame; this replay does not prove a live input or outcome. The manual-13 image has a clock at the right edge and is rejected by this path; manual-20/24/31/35 have extracted North overlaps and are rejected. A displayed North extraction on 7e79853 monitor-5 retains priority over discard.

Negative tests paste existing button-row fixtures for North extraction, pon/kan, riichi, tsumo and four-player ron, both across the full row and just the right slot, as well as synthetic black occlusions. Those fixtures share limited theme/layout coverage, and the two ron examples are four-player. The portable blank-row test uses the very same reference, so it is not independent validation. Real full-frame checks and the resident-replay test skip when their local image/receipt are absent. No accuracy or win-rate claim follows from these experiments.

A portable redacted hand/row fixture and a derived receipt now exercise the same mock shape selection and digest binding without local captures. Their provenance, the rewritten digest and limitations are documented in `python/fixtures/sanma-full-empty-row/README.md`; the fixture is not a fresh recognition run or a play test. Full-frame real-image tests remain conditional on local captures.

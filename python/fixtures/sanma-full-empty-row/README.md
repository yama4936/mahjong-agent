# Redacted friend-frame hand and action row

`redacted-hand-row.png` is derived from cd82c23 `manual-1-before.png`, SHA-256 `abe18e6467dede9664e9836665ed877267ac8859cb03f4ba910ea802bde9906a`. The original is a 1920×1080 CPU friend-match image. Only three rectangles retain original pixels: action row `(600,785)-(1425,875)`, hand `(223,921)-(1579,1072)`, and the own-riichi rail `(875,516)-(1035,531)`. Everything else is solid black, omitting names, avatars and other player information. Pixel coordinates are unchanged. The image SHA-256 is `842459f74a7f356411e6c95af04c4d76d1a1145084831a4789b3a7be4d79d71f`.

`receipt.json` is a **derived test fixture**, not a fresh recognizer output for the redacted image. It contains only hand, hand geometry and action-row data plus structural candidates from the original image's offline resident replay. Other observation fields and conditional public evidence were removed, and the three digest fields were rewritten to match the redacted PNG. Candidate labels, coordinates and shape estimates were not independently verified. The test checks these digest fields against the actual file, then passes the fixture through the existing shape-selection adapter with mocked threat detection and mocked discard execution. It also verifies that a mismatched source digest blocks processing, and a mismatched structural digest cannot cause a hand discard.

The redacted image and receipt do not establish screenshot freshness, recognizer behavior on the redacted image, real session identity, opponent threats, valid turn, actual screen input, or match outcome. Button-row examples and synthetic black overlays form negative fixtures, not independent full-game captures. The single image and one match/theme cannot establish general accuracy or win rate.

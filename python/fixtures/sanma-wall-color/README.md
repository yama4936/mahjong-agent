# Anonymized wall crops for friend-mode color veto

Each RGB PNG is a 240×620 crop of native 1920×1080 gameplay coordinates `(150,80)-(390,700)`. The same polygon `(174,0),(240,0),(240,160),(84,545),(10,545),(10,480)` is retained in every image; all other pixels are replaced by solid RGB `(25,35,55)` to remove surrounding names and user interface. The retained wall and adjacent felt contain no player names or avatars. Pixels within the polygon are unchanged. The test pastes the crop back at `(150,80)` on a synthetic 1920×1080 canvas. The color veto sees the same rectangle and coordinates, but the rest of the scene is synthetic; these fixtures do not validate recognition, whole-frame stability, pre-click checks, or actual inputs.

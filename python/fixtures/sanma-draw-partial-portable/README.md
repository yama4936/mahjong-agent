# Friend draw partial-row crops

These images are 825×110 crops of the action-row area at native coordinates (600,765)–(1425,875) from two CPU friend-match screenshots. They contain no player names or avatars. `north.png` retains the left edge of the visible overlapping extracted north tiles; `empty.png` shows the separately observed empty visible region. Tests paste the crop into a synthetic frame and verify both the image-candidate branches and rejection of added visible marks. The hidden area remains unknown; the fixtures do not prove turn, legality, or classification accuracy.

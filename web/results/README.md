# 対局記録サイト

段位戦・友人戦を分け、1対局ごとの最終結果画像と局結果画像を閲覧する静的サイトです。

## 更新

リポジトリのルートで `node web/results/export.mjs .` を実行します。既存の sharp 依存を使用します。生成先は `web/results/dist/`（Git対象外）。`python3 -m http.server 8766 --directory web/results/dist` でローカル表示できます。

公開先の Site ID は `.openai/hosting.json` に保存されています。Sites の既存サイト更新手順で、このディレクトリと生成済み dist を独立した Sites チェックアウトへ同期・パッケージ化・非公開デプロイしてください。生成だけでは公開先は更新されません。

## データの範囲

- artifacts 以下の python-operator.jsonl の outcome_observed / match を対局終了記録として採用。
- 同一の結果画像は SHA-256 で重複除外。同じ実行内の60秒未満の再検出も除外。
- matches/*.json と ranked-match-results.jsonl の確定結果を画像ファイル名で照合。
- 2026-10-26 JSTの8件は、2026-10-27に実際に閲覧した最終結果画像から順位と点数を補完。
- 最終結果が記録されていない実行は「終了未確認」。再起動を含み、独立した対局数ではありません。
- 順位未確認・終了未確認を順位統計に含めません。対局途中の点数から最終順位を推測しません。
- 友人戦と段位戦の統計は分離。全記録タブで混合勝率は出しません。
- 時間設定は実行名由来、操作期限は記録値です。前者が実際の設定画面で独立確認されたことを意味しません。
- 結果画像を WebP に変換して同梱します。元ログ全体、認証情報、ブラウザプロファイルは配信しません。
- 各局画像はその実行ログ内で最終結果までに観測した順序です。再起動前の局が欠ける場合があります。
- 静的スナップショットです。新しい対局を載せるには再生成・再公開が必要です。

## 検証

`node --check web/results/export.mjs`

`node --check web/results/src/app.js`

`node web/results/verify.mjs` （生成後）

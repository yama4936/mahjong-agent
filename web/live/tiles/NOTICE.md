# Tile images

Unmodified base tile crops from `pjura/mahjong_souls_tiles`.

- Author/publisher: pjura
- Source: https://huggingface.co/datasets/pjura/mahjong_souls_tiles
- Revision: `8c0f22e7c6b64be55bb1d2767fe1a63981788de7`
- Original paths: `dataset/test/<class>/<class>.png`
- License declared by publisher: Apache-2.0 (included in LICENSE).

These 34 images reuse this repository's bootstrap templates. `m`, `p`, `s`
denote characters, circles, and bamboo. E/S/W/N/P/F/C denote east, south,
west, north, white, green, and red dragons. Red fives use the corresponding
five image with a separate visible red badge and an explicit accessible name.
